# 撮り方の条件と精度の実験（PDCA）

`robustness.py` は、本物の写真（`tests/data/japanese_coins.jpg`、硬貨5枚、10円玉を物差し）をもとに、撮り方の条件を1つずつ悪くした画像を作り、個数と直径の誤差を調べます。**個数が5で、直径の誤差が3%以内**なら OK です。

```powershell
pixi run python experiments/robustness.py   # 結果は experiments/out/robustness.csv
```

## 1回目（2026-11-02）

| 条件 | 強さ（左ほど良い条件） | OK の数 |
|---|---|---|
| 傾き（度） | 0 / 10 / 20 / 30 / 40 | 1 / 5 |
| 暗さ | 0 / 0.3 / 0.5 / 0.7 / 0.85 | 2 / 5 |
| ぼけ | 0 / 3 / 7 / 12 / 20 | 3 / 5 |
| ノイズ | 0 / 10 / 25 / 40 / 60 | 3 / 5 |
| 片側の影 | 0 / 0.3 / 0.5 / 0.7 / 0.85 | 1 / 5 |
| 硬貨を寄せる（px） | 0 / 60 / 100 / 130 / 160 | 2 / 5 |
| 背景を灰色に | 0 / 0.3 / 0.6 / 0.8 / 1.0 | 5 / 5 |
| **合計** | | **17 / 35** |

### わかったこと（Check）
- **暗い写真で1個も見つからない**: 背景が明るいかどうかを「明るさ127より上か」で決めていたため、暗い部屋で撮った白い紙を黒い布と判断していた
- **強いノイズで1個も見つからない**: ノイズが輪郭として拾われ、画面全体が1つの物になって「縁に触れた物」として消えた
- **片側の影で数が減る**: 画面全体で1つの明るさの境目を使うため、影の側の背景が物として扱われた
- **硬貨が近いと1個になる**: くっついた物を分ける仕組みがなかった
- **傾けると大きさがずれる**: 遠い物ほど小さく写る。硬貨を物差しにする方法では原理的に直せない

## 改善（Act）
1. **照明のむらをならす**: 縮小した画像で、物より大きい窓で背景の明るさを推定し、その明るさで割る
2. **背景の明暗の決め方を変える**: 明るい背景・暗い背景の両方の前提で2値化し、画像の縁がより背景として残るほうを選ぶ
   - 途中で「縁と全体の明るさを比べる」方法も試したが、中央だけ明るい照明で間違えたのでやめた
3. **ノイズ対策**: メディアンフィルタをかける。輪郭の結果が画面の60%以上を占めたら使わない
4. **くっついた物を分ける**: くびれのある形だけ、距離変換の山を種にして Watershed で分ける
5. **マーカーで斜めのゆがみを直す**: マーカーが正方形に写るよう画像を変形してから測る（マーカーを使うときだけ）

## 3回目（背景と物の明るさが近いとき）

### Plan
2回目で唯一悪くなった「背景を灰色に」（7個と数える）を直す。灰色の机の上では、銀色の硬貨は背景より**明るく**、10円玉は背景より**暗く**写るので、「明るい方向にも暗い方向にも背景から外れた所」を物とする方法（背景の明るさを2次曲面で近似し、そこからの外れ具合と色の違いで判定）を試す。

### Do / Check
| 方法 | OK の数（35通り） |
|---|---|
| 2回目までの方法（明暗どちらか一方） | 28 |
| 新しい方法（明暗の両方向＋色） | **6**（元の写真でも 4 個しか数えられない） |

新しい方法が悪かった理由: **白い紙の上の1円玉**（アルミ。紙との明るさの差が小さい）が「外れ具合が小さい」と判定され、縁の輪っかしか残らなかった。差の大きい硬貨に合わせて境目が高く決まり、差の小さい物を取りこぼす。

さらに、失敗した画像を見直すと、**実験の画像の作り方が間違っていた**。「明るさ 200 より上の画素だけ灰色に置き換える」作り方のため、紙の少し暗い部分が白く残り、背景が**白と灰色のまだら**になっていた。本物の灰色の机とは違う。

### Act
1. 実験の作り方を直した: 硬貨の部分はそのまま、背景だけを明るさの比率で暗くする（影や照明のむらは残る）。条件は「背景の明るさ 225（白い紙）/ 190 / 170 / 150 / 120」
2. 直した実験で比べ直した: 2回目までの方法は **225〜150 で OK**（銀色の硬貨と背景がほぼ同じ明るさの 170 でも測れた）。新しい方法は 5 段階すべて NG
3. **新しい方法は採用しない**（コードからも消した）。2回目で「灰色の背景に弱い」と見えたのは、測り方ではなく実験の作り方のせいだった

### 結果（3回目のあと）
| 条件 | OK の数 |
|---|---|
| 傾き（度） | 1 / 5（マーカーを使えば補正できる） |
| 暗さ | 4 / 5 |
| ぼけ | 5 / 5 |
| ノイズ | 5 / 5 |
| 片側の影 | 5 / 5 |
| 硬貨を寄せる（px） | 4 / 5 |
| 背景の明るさ（225〜120） | 4 / 5（120 の暗い灰色だけ NG） |
| **合計** | **28 / 35** |

**学び**: 実験の結果が悪いときは、測り方だけでなく**実験の作り方も疑う**。失敗した画像を目で見て確かめる。

## 結論: 撮り方のルール

ソフトで直せるものは直し、直せないものは撮り方のルールにする。

| ルール | 理由 |
|---|---|
| **真上から撮る**（硬貨を物差しにするとき） | 10度傾くだけで誤差が 9% になる。マーカーを使えば斜めでも補正できる |
| **背景は白い紙か、明るい灰色にする** | 白い紙〜明るい灰色（明るさ 150）までは、銀色の硬貨も 10 円玉も測れた。暗い灰色（120）だと、明るい物と暗い物が混ざって見分けられない |
| **暗すぎる場所で撮らない** | 明るさ 15% まで落ちると見つからない。30% までは大丈夫 |
| **物同士は少し離す** | 少し触れる程度なら分けられるが、重なると誤差が大きくなる |
| ぼけ・ノイズ・影は気にしなくてよい | 強いぼけ・ノイズ・片側の影でも誤差 3% 以内 |

## 次の PDCA で試すこと

- 暗い灰色の背景（明るい物と暗い物が混ざる）への対策。今は撮り方のルールで避ける
