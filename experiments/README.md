# 撮り方の条件と精度の実験（PDCA）

`robustness.py` は、本物の写真（`tests/data/japanese_coins.jpg`、硬貨5枚、10円玉を物差し）をもとに、撮り方の条件を1つずつ悪くした画像を作り、個数と直径の誤差を調べます。**個数が5で、直径の誤差が3%以内**なら OK です。

```powershell
pixi run python experiments/robustness.py   # 結果は experiments/out/robustness.csv
```

## 1回目（2026-11-02）

| 条件 | 強さ（左ほど良い条件） | OK の数 |
|---|---|---|
| 傾き（度） | 0 / 10 / 20 / 30 / 40 | 1 / 5 |
| 暗さ | 0 / 0.3 / 0.5 / 0.7 / 0.85 | 2 / 5 |
| ぼけ | 0 / 3 / 7 / 12 / 20 | 3 / 5 |
| ノイズ | 0 / 10 / 25 / 40 / 60 | 3 / 5 |
| 片側の影 | 0 / 0.3 / 0.5 / 0.7 / 0.85 | 1 / 5 |
| 硬貨を寄せる（px） | 0 / 60 / 100 / 130 / 160 | 2 / 5 |
| 背景を灰色に | 0 / 0.3 / 0.6 / 0.8 / 1.0 | 5 / 5 |
| **合計** | | **17 / 35** |

### わかったこと（Check）
- **暗い写真で1個も見つからない**: 背景が明るいかどうかを「明るさ127より上か」で決めていたため、暗い部屋で撮った白い紙を黒い布と判断していた
- **強いノイズで1個も見つからない**: ノイズが輪郭として拾われ、画面全体が1つの物になって「縁に触れた物」として消えた
- **片側の影で数が減る**: 画面全体で1つの明るさの境目を使うため、影の側の背景が物として扱われた
- **硬貨が近いと1個になる**: くっついた物を分ける仕組みがなかった
- **傾けると大きさがずれる**: 遠い物ほど小さく写る。硬貨を物差しにする方法では原理的に直せない

## 改善（Act）
1. **照明のむらをならす**: 縮小した画像で、物より大きい窓で背景の明るさを推定し、その明るさで割る
2. **背景の明暗の決め方を変える**: 明るい背景・暗い背景の両方の前提で2値化し、画像の縁がより背景として残るほうを選ぶ
   - 途中で「縁と全体の明るさを比べる」方法も試したが、中央だけ明るい照明で間違えたのでやめた
3. **ノイズ対策**: メディアンフィルタをかける。輪郭の結果が画面の60%以上を占めたら使わない
4. **くっついた物を分ける**: くびれのある形だけ、距離変換の山を種にして Watershed で分ける
5. **マーカーで斜めのゆがみを直す**: マーカーが正方形に写るよう画像を変形してから測る（マーカーを使うときだけ）

## 2回目（改善後）

| 条件 | OK の数 | 1回目から |
|---|---|---|
| 傾き（度） | 1 / 5 | 変わらず（硬貨を物差しにする方法では直せない） |
| 暗さ | 4 / 5 | +2 |
| ぼけ | 5 / 5 | +2 |
| ノイズ | 5 / 5 | +2 |
| 片側の影 | 5 / 5 | +4 |
| 硬貨を寄せる（px） | 4 / 5 | +2（160px はほぼ重なっていて、誤差 4.0%） |
| 背景を灰色に | 4 / 5 | **−1**（背景が完全に灰色になると、銀色の硬貨と区別できず 7 個と数える） |
| **合計** | **28 / 35** | **+11** |

**マーカーを使う場合の傾き**: 合成画像を 15・30・40 度に傾けても、ゆがみを直して個数は正解、長さの誤差は 5% 以内（`tests/test_measure.py::test_tilted_photo_is_rectified`）。

## 結論: 撮り方のルール

ソフトで直せるものは直し、直せないものは撮り方のルールにする。

| ルール | 理由 |
|---|---|
| **真上から撮る**（硬貨を物差しにするとき） | 10度傾くだけで誤差が 9% になる。マーカーを使えば斜めでも補正できる |
| **背景は物と違う色にする**（銀色の物なら黒い布） | 背景と物が同じ明るさだと、どんな処理でも見分けられない |
| **暗すぎる場所で撮らない** | 明るさ 15% まで落ちると見つからない。30% までは大丈夫 |
| **物同士は少し離す** | 少し触れる程度なら分けられるが、重なると誤差が大きくなる |
| ぼけ・ノイズ・影は気にしなくてよい | 強いぼけ・ノイズ・片側の影でも誤差 3% 以内 |

## 次の PDCA で試すこと
- 背景が物と同じ明るさのときに、色（色相・彩度）も使って分ける
- 自分で撮った写真（マーカーあり、斜め・暗い部屋など）で同じ表を作る
- 硬貨以外（ネジ・ナット・豆など、形が丸くない物）で試す
